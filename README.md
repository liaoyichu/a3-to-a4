# A3 试卷转 A4

一个纯网页小工具：把 A3 的试卷（PDF，或者手机拍的照片）转成一张张 A4，
方便家里的 A4 打印机打印，也方便直接在微信里转发给别人。

**打开就用：[https://liaoyichu.github.io/a3-to-a4/](https://liaoyichu.github.io/a3-to-a4/)**

## 特点

- **全部在浏览器里完成**，试卷不会上传到任何服务器，也不依赖谁家的电脑开着。
- A3 横向的试卷按「左右对半」切成两张 A4；竖向的按「上下对半」。拿不准就选「自动」。
- 输出两样：一张张 A4 图片（手机上**长按就能存相册**，然后微信转发），
  以及一份 A4 的 PDF（用来打印）。
- 手机上也能用，就是微信里点开这个网址。

## 技术说明

- 单文件 `index.html`，无构建步骤。
- PDF 渲染用 [pdf.js](https://mozilla.github.io/pdf.js/)，拼 PDF 用 [pdf-lib](https://pdf-lib.js.org/)，
  两者都从 BootCDN 加载（国内可访问）。
- 为了让手机不崩，单页渲染上限约 800 万像素（A3 约 200dpi）。
- 拆分方向有个坑：横向 A3 左右切出来才是竖向 A4；竖向 A3 上下切出来是**横向** A4，
  所以输出页的方向跟着切出来的形状走，不硬转。

## 部署

把这个文件夹推到 GitHub，在仓库 Settings → Pages 里选 `main` 分支根目录即可。
